AI逆向助手 AIReverse

一个可安装在 iOS 设备上的 AI 聊天式逆向分析工具：本地解析 Mach-O / IPA / App，并把分析结果注入 AI 上下文，用自然语言完成解读、排查与破解辅助。

这是什么

AIReverse 是一个纯 Swift 实现的 iOS 逆向工作台。它不依赖 Ghidra / IDA，直接在设备上解析 Mach-O fat/64 头、Load Commands、ObjC 类与方法、符号表与字符串，然后以 OpenAI 兼容的 chat/completions 协议把静态分析结果喂给任意大模型，实现「对着二进制聊天」。

项目已从单纯的静态分析演进为一个完整的逆向工作台：内置带工具调用的编码助手（读写文件、Git 操作）、dylib 注入、root 提权、已安装应用管理、仓库（GitHub）管理与 MCP 支持。

核心功能

本地静态分析

纯 Swift 解析 Mach-O（fat/64、Load Commands、segments）、ObjC 元数据、符号表、可读字符串（URL / key 等可疑串），附 ARM64 轻量反汇编。

AI 对话解读

分析结果自动注入系统提示，支持函数调用工具循环，可追问反汇编解读、逻辑梳理、注入点排查。

自定义模型

Base URL / API Key / 模型名全可配置，多套配置保存切换，兼容 DeepSeek、OpenAI、Kimi、Ollama 等任意 OpenAI 兼容接口。

dylib 注入

纯 Swift 注入 LC_LOAD_DYLIB（MachOEditor），替代 insert_dylib / jtool；失败自动回退 Info.plist DYLD_INSERT_LIBRARIES，适配 Relaxin / Rootless。

编码助手

内置工具调用编码代理：读/写文件、list_dir、git status / branch / log / commit、仓库概览，后台任务可恢复。

root 提权

su 提权 + RootService 守护进程 socket 双通道，自动探测 Procursus / Rootless 工具路径，权限失败给出明确引导。

应用与文件管理

导入 .tipa / .ipa / .app / 裸 Mach-O，扫描已安装应用，解析 .deb 包，仓库克隆与浏览，文件注入与数据修改。

MCP 支持

可配置多个 MCP Server，把外部工具能力接入 AI 对话，扩展工作流。

构建（本地 Mac + Xcode）

需要 macOS + Xcode 16+。仓库根目录提供一键脚本 build_ipa.sh：

xcodebuild -project AIReverse.xcodeproj -scheme AIReverse \
  -configuration Release -derivedDataPath build \
  -destination 'generic/platform=iOS' \
  CODE_SIGNING_ALLOWED=NO build
# 产物：build/AIReverse.ipa（未签名，适配 TrollStore）

构建（GitHub Actions，无需 Mac）

仓库自带 .github/workflows/build-ipa.yml：在 GitHub 仓库 Actions 页手动运行 Build IPA workflow（或推送 v* tag 自动触发），在运行详情页下载 AIReverse.ipa 产物，用 TrollStore 打开安装即可。

安装与配置

  • 用 TrollStore 打开并安装生成的 .ipa（越狱环境也可用其他方式安装）。
  • 首次使用：在「模型设置」添加模型（Base URL / API Key / 模型名）。
  • 「分析」选择目标文件 → 切到「AI 对话」开始提问。
  • 需要注入 / 修改系统级文件时：按引导配置 root 权限（NewTerm 中 su root 启动 /var/mobile/root_service，或配置 LaunchDaemon 以 root 运行）。

环境与密钥

构建与运行 不需要任何环境变量或 API Key。唯一的密钥是 AI 模型服务的 API Key，在 App 内「模型设置」里填写，数据直接发送到你配置的服务，不经过任何第三方中转。

✔ 本地编译：macOS + Xcode 16+（本容器无 Swift/Xcode 工具链，验证需在 Mac 或 GitHub Actions 完成）。
⚠ 本预览为项目文档静态页；真实产物是 iOS 原生 App，无法在浏览器中运行。

说明

本工具仅用于合规的安全研究、CTF、自身 App 的调试分析等正当用途。
